Backup 备份与恢复

Your articles live only on this phone (in the app's own database). 你的文章只存在这台手机里，所以请偶尔导出一份 JSON 备份，存到 iCloud 或发给自己。

Import replaces everything currently in the library — you will be asked to confirm first. 导入会替换掉现在的全部内容，导入前会先弹窗确认。

Honest note: new articles get in by pasting or by JSON import. There is no automatic sync from any chat app — that is a future plan, not a current feature. 如实说明：目前没有自动同步功能，新文章靠粘贴或 JSON 导入，这是已实现和未来计划的区别。
